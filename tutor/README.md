# سَنَد — المدرّس الافتراضي

موقع تعليمي فيه مدرّس خصوصي بالذكاء الاصطناعي (Claude) لطلاب الكويت، من الصف الأول إلى الجامعة، بالعربي والإنجليزي.

> **الحالة الحالية: المرحلة 1** (الأساس والمدرّس). تفاصيل ما تم وما بقي في [`docs/PROJECT-STATUS.md`](docs/PROJECT-STATUS.md).

---

## تشغيل الموقع على جهازك

تحتاج برنامج **Node.js** (الإصدار 20.9 أو أحدث) من nodejs.org.

```bash
cd tutor
npm install          # تثبيت الحزم (مرة واحدة)
cp .env.example .env.local
npm run dev          # تشغيل الموقع
```

ثم افتح المتصفح على: http://localhost:3000

## إضافة مفتاح Claude

1. ادخل **console.anthropic.com** وسجّل حساباً.
2. من **Billing** اشحن رصيداً (5–10$ تكفي للتجربة).
3. من **API Keys** اضغط **Create Key** وانسخ المفتاح.
4. افتح ملف `.env.local` وضع المفتاح بعد `ANTHROPIC_API_KEY=`.
5. أعد تشغيل الموقع.

بدون مفتاح، يعمل الموقع في **الوضع التجريبي**: ردود نموذجية تُظهر الشكل (جداول، معادلات) بدون أي تكلفة.

⚠️ لا تضع المفتاح أبداً في أي ملف غير `.env.local`، ولا ترسله لأحد. المفتاح يبقى على السيرفر ولا يصل للمتصفح.

## أين أغيّر الإعدادات؟

| ماذا تريد؟ | أين؟ |
|---|---|
| الموديلات، الحدود، الأسعار | `src/config/ai.ts` |
| عدد رسائل الزائر اليومي | متغير `GUEST_DAILY_MESSAGE_LIMIT` في `.env.local` |
| الصفوف والمواد | `src/config/catalog.ts` (ستنتقل للوحة الإدارة في المرحلة 2) |
| تعليمات المدرّس (System Prompt) | `src/lib/tutor/prompt.ts` |
| نصوص الواجهة بالعربي والإنجليزي | `src/lib/i18n/dictionaries.ts` |
| الألوان والخطوط | `src/app/globals.css` |

```bash
npm run check   # فحص الأنواع + فحص الكود + الاختبارات + بناء الموقع
```

يجب أن ينجح كاملاً قبل نشر أي تعديل.

## هيكل المشروع (للمبرمجين)

- **Next.js 16 + TypeScript + Tailwind 4**، بلا قاعدة بيانات في المرحلة 1.
- `src/app/api/chat/route.ts` — يستقبل سؤال الطالب، يتحقق منه (الطول، المصدر، حدود الاستخدام)، ويرسل الرد كلمة بكلمة (Streaming).
- `src/lib/tutor/claude.ts` — الاتصال بـ Claude عبر الحزمة الرسمية `@anthropic-ai/sdk`، مع Prompt Caching وإعادة المحاولة التلقائية والتحويل لموديل بديل عند الرفض.
- `src/lib/tutor/prompt.ts` — جزء ثابت (يُخزَّن مؤقتاً لتقليل التكلفة) + جزء خاص بكل طالب.
- `src/components/Markdown.tsx` — عرض الردود: جداول، معادلات KaTeX، كود ملوّن، واتجاه صحيح لكل فقرة. لا يعرض HTML خام (حماية من XSS).
- `src/lib/rate-limit.ts` — حدود الاستخدام في ذاكرة السيرفر (مؤقت، ينتقل لقاعدة البيانات في المرحلة 3).
- `tests/` — اختبارات آلية (`npm test`).
