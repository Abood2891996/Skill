# نموذج طلب بنظام RTCCO

انسخ النموذج واملأ ما تعرفه فقط. أي جزء تتركه فارغًا سيكمله Claude من معلومات المشروع، ويسألك فقط عمّا لا يمكن معرفته.

```
الدور: (من تريد أن يكون؟ مثال: كاتب محتوى تسويقي / مسؤول توظيف / مطوّر مواقع)
المهمة: (ما المطلوب بالضبط؟)
السياق: (معلومات مهمة: لمن هذا؟ لماذا؟ ما الموجود حاليًا؟)
القيود: (ما الممنوع أو الشروط؟ اللغة، الطول، لا وعود غير حقيقية…)
شكل النتيجة: (كيف تريدها؟ منشورة على الموقع / ملف PDF / نص / جدول)
```

## أمثلة

**إضافة وظيفة**
```
الدور: مسؤول توظيف في JoDesx
المهمة: أضف وظيفة "مشرف جودة خدمة العملاء"
السياق: دوام كامل، حضوري في عمّان، خبرة سنتين، إنجليزية ممتازة والعربية ميزة
القيود: بدون ذكر الراتب، وبنفس أسلوب الموقع
شكل النتيجة: انشرها على الموقع وأرسل لي الرابط
```

**منشور لينكدإن**
```
الدور: كاتب محتوى B2B
المهمة: منشور يعرّف بخدمة الإشراف على المحتوى
السياق: الجمهور مدراء منصات إلكترونية في أوروبا والخليج
القيود: بدون أرقام أو عملاء غير حقيقيين، أقل من 150 كلمة
شكل النتيجة: نص جاهز للنشر بالإنجليزية مع ترجمة عربية
```
