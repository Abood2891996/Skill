# RTCCO request template

Copy it and fill in only what you know. Claude completes the rest from the project context and asks only about what it cannot infer.

```
Role: (which expert? e.g. B2B copywriter / recruiter / web developer)
Task: (what exactly is needed?)
Context: (who is it for, why, what exists already?)
Constraints: (what's forbidden or required: language, length, no unverified claims…)
Output: (published on the site / PDF / text / table)
```

## Example

```
Role: Recruiter at JoDesx
Task: Add a "Customer Support Quality Lead" job posting
Context: Full-time, on-site in Amman, 2 years' experience, excellent English, Arabic a plus
Constraints: No salary, same tone as the site
Output: Publish it on www.jodesx.com and send me the link
```
