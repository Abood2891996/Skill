# خطة تطبيق الأمان — JoDesx

**قاعدة ذهبية:** لا ترسل وثيقة `JoDesx-Security-Overview.pdf` لأي عميل قبل إكمال البنود المطلوبة قبل الإرسال (✅) أدناه، لأن الوثيقة تَعِد العميل بها.

## قبل إرسال الوثيقة لأي عميل (✅ مطلوب)
1. ✅ **عنوان security@jodesx.com** — Zoho Admin Console ← Users ← حسابك ← Mail Aliases.
2. ✅ **التحقق بخطوتين (2FA)** على: GitHub، Vercel، Zoho، Resend، Google، Spaceship، LinkedIn، Bitwarden. وفي Zoho اجعله **إلزاميًا لكل الموظفين** من Admin Console ← Security ← Multi-factor authentication.
3. ✅ **Bitwarden Teams** — أنشئ "Organization" باسم JoDesx، ومجموعة (Collection) لكل عميل، ومجموعة "Management" لمفاتيح استرداد تشفير الأجهزة.
4. ✅ **أجهزة الشركة** — اشترِ أجهزة **Windows 11 Pro** (وليس Home، لأن تشفير BitLocker يحتاج Pro) أو **Mac**، وجهّزها حسب القائمة B في ملف Checklists.
5. ✅ **إدارة الأجهزة (MDM)** — اختر أداة تسمح بقفل الجهاز ومسحه عن بُعد، ثم **جرّب القفل والمسح فعلًا** قبل تسليم أي جهاز. خيارات شائعة: Microsoft Intune (ضمن Microsoft 365 Business Premium)، أو ManageEngine Endpoint Central. تحقق من الأسعار والنسخ المجانية قبل الشراء.
6. ✅ **اتفاقية السرية** — أعطِ المسودة لمحامٍ أردني لمراجعتها وتحويلها إلى العربية أو نسخة بلغتين، ثم يوقّعها كل موظف قبل أي وصول.
7. ✅ **فحص الموظفين** — هوية + شهادة عدم محكومية + مراجع، قبل منح أي صلاحية.
8. ✅ **السياسة والتدريب** — كل موظف يقرأ Information Security Policy ويوقّع آخر صفحة، مع جلسة تدريب قصيرة (ساعة).
9. ✅ **المكتب** — دخول مقيّد للموظفين، وسجل للزوار، وإنترنت احتياطي (راوتر 4G/5G)، وجهاز UPS.

## روتين ثابت
- **شهريًا:** تأكد في أداة MDM أن كل الأجهزة مشفّرة ومحدّثة، واحذف طلبات التوظيف الأقدم من 6 أشهر.
- **كل 3 أشهر:** راجع قائمة الصلاحيات مع كل عميل وأزل غير المطلوب.
- **سنويًا:** تدريب تذكيري لكل الموظفين، ومراجعة السياسة والوثائق، وتحديث رقم الإصدار.

اتبع القائمة D في ملف Checklists. **أبلغ العميل خلال 24 ساعة من تأكيد الحادث** إذا كانت بياناته قد تأثرت.
